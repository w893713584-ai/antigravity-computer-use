# Dual-Tier Human Takeover With Target-Scoped Arming and Drain Gate

We arm Human Takeover strictly around verified active automation targets, explicit Side-Pane Mini-Window actions, and the reserved emergency-stop shortcut — rejecting global pointer-idle heuristics and time-window event suppression that either false-trigger when the user works in Antigravity or swallow real mid-click takeovers — backed by a two-tier sensor (`Enhanced` via `CGEventTap` in `CUADesktopHelper.app`, or automatic `Baseline` fallback via workspace notifications plus Mini-Window controls). Every takeover synchronously advances a monotonic Pause Epoch and closes a Drain Gate before dispatching manual Mini-Window inputs so queued or retried AI actions from earlier epochs can never bleed across unpause boundaries.
