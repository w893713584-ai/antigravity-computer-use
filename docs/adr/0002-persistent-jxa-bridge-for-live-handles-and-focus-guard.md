# Persistent JXA Bridge for Live Handles and Focus Guard Alongside Prebuilt Native Companion Bundles

We keep the persistent JXA (`osascript -l JavaScript`) ObjC/AppKit/AXUIElement coprocess (`PersistentAxBridge`) for live accessibility element handles, `window_post` / `window_key` coordinate delivery, and Focus Guard sweeps, while shipping prebuilt universal (`arm64` + `x86_64`) Swift/C companion bundles (`CUADesktopHelper.app` and `CUAScriptRunner.app`) for kernel Seatbelt script sandboxing, `CGEventTap` takeover sensing, and `ScreenCaptureKit` video encoding instead of requiring an Xcode toolchain on end-user machines. Prebuilt inner payloads verified by manifest SHA-256 and `codesign` preserve instant friend installation without build tools while retaining zero-popup JXA AX/focus integration.
