# Window-Scoped Focus Attribution and Structured Delivery Receipts

We scope adaptive Delivery Route penalties to a frozen Route Scope (`pid`, process token, and target window ID) rather than global app aliases, isolate click routes from keyboard routes, separate dispatch from read-back observation phases while keeping ADR-0003 pure `window_post`, and pass structured Delivery Receipts through a non-enumerable broker attachment instead of regex-parsing formatted text. Globally blacklisting an application alias caused legitimate window-creation Focus Steals (such as opening a new editor window from a home screen) or post-action read-back activations to permanently degrade explicit `sky_click` into `window_post` across subsequent windows and keyboard calls, while regex-parsing UI footers broke when arbitrary AX text appeared in output or when read-back failed.
